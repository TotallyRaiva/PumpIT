Frequently Asked Questions

Where do the fuel prices come from?

All fuel prices (Super E5, Super E10, Diesel) are provided in real time via the official Tankerkönig API (CC BY 4.0), which receives official market transparency data from Germany's Markttransparenzstelle für Kraftstoffe (MTS-K).

Why does PumpIT only show stations in Germany?

The MTS-K fuel price feed covers petrol stations registered in Germany. You can search any German city or region using the search bar at the top of the map, even if you are currently located outside Germany.

How do I configure my own Tankerkönig API key?

Open Settings (⚙️) inside PumpIT and paste your personal key under Tankerkönig API Key. You can register for a free API key at creativecommons.tankerkoenig.de.

Häufig gestellte Fragen (FAQ)

Woher stammen die Spritpreise?

Alle Kraftstoffpreise (Super E5, Super E10, Diesel) werden in Echtzeit über die Tankerkönig-API (CC BY 4.0) bezogen, die die offiziellen Daten der Markttransparenzstelle für Kraftstoffe (MTS-K) beim Bundeskartellamt bereitstellt.

Warum werden nur Tankstellen in Deutschland angezeigt?

Das MTS-K-Meldesystem umfasst Tankstellen innerhalb Deutschlands. Über die Suchleiste am oberen Bildschirmrand können Sie jederzeit beliebige deutsche Städte oder Regionen durchsuchen.

Wie kann ich einen eigenen Tankerkönig-API-Schlüssel hinterlegen?

Öffnen Sie in der App die Einstellungen (⚙️) und tragen Sie Ihren Schlüssel im Feld Tankerkönig API Key ein. Einen kostenlosen Schlüssel erhalten Sie unter creativecommons.tankerkoenig.de.
